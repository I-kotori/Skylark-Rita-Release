## ⭐ 리타는 무엇인가요?

메이플스토리를 하다 보면 캐릭터 정보를 찾아보거나, 다음 레벨까지 걸리는 시간을 계산하거나, 강화에 필요한 메소를 알아볼 일이 생깁니다. 그때마다 사이트를 옮겨 다니고 계산기에 값을 넣는 일이 번거롭게 느껴졌어요.

**종달새 리타는 이런 조회와 계산을 카카오톡 대화 안에서 할 수 있도록 만든 챗봇입니다.**

게임 정보 커뮤니티를 운영하며 자주 접했던 질문들을 하나씩 기능으로 옮기고 있습니다. 현재는 캐릭터 정보, 경험치와 성장 이력, 강화 확률과 기댓값 등 **20개 이상의 조회·계산 기능**을 연결했습니다.

## 💬 이렇게 물어보세요

리타가 연결된 카카오톡 채팅방에서 **`리타야 기능 알려줘`**라고 물어보세요. 안내된 기능을 보고, 궁금한 내용을 하나씩 물어보면 됩니다.

아래는 리타에게 요청할 수 있는 질문의 예시입니다. 베타테스트 중에는 표현에 따라 추가 질문을 하거나, 필요한 정보를 다시 물을 수 있습니다.

| 궁금한 내용 | 질문 예시 |
| --- | --- |
| 사용할 수 있는 기능 | `리타야 기능 알려줘` |
| 캐릭터 정보 | `리타야 네루아 캐릭터 정보 알려줘` |
| 경험치 획득 이력 | `리타야 네루아 경험치 기록 알려줘` |
| 목표 레벨까지 걸리는 시간 | `리타야 캐릭터이름 '네루아' 300레벨까지 얼마나 걸려?` |
| 스타포스 강화 기댓값 | `리타야 200제 장비 12성에서 22성까지 기댓값 얼마야?` |

캐릭터를 조회할 때는 **캐릭터 이름**, 강화 비용을 계산할 때는 **장비 레벨과 현재·목표 강화 단계**를 함께 적어주면 좋습니다.

## ✨ 무엇을 도와주나요?

### 🔎 캐릭터 정보 조회

캐릭터 이름을 바탕으로 게임 정보를 찾아봅니다. 직접 검색 사이트를 열지 않고도 채팅방에서 필요한 정보를 확인할 수 있습니다.

### 📈 경험치와 성장 확인

캐릭터의 경험치 획득 이력을 확인하고, 이를 바탕으로 목표 레벨까지 걸리는 시간을 예상합니다. 앞으로의 플레이에 따라 달라질 수 있으니 성장 계획을 세울 때 참고해 주세요.

### 🧮 강화 확률과 기댓값 계산

장비 레벨과 강화 조건에 맞춰 확률과 기댓값을 계산합니다. 기댓값은 여러 번 시도했을 때의 평균을 뜻하므로, 실제 강화 결과나 지출을 보장하는 값은 아닙니다.

### 🗣️ 자연어 요청과 대화

일상적인 말로 궁금한 내용을 물어볼 수 있습니다. 정보가 부족하면 추가로 질문하고, 아직 지원하지 않는 요청은 안내합니다. 현재는 같은 뜻의 질문을 표현이 달라도 잘 알아듣도록 다듬고 있습니다.

## 🛠️ 지금 다듬고 있는 부분

**같은 뜻의 질문을 같은 기능으로 연결하는 것**이 현재의 주요 개선 과제입니다.

예를 들어 “특정 캐릭터가 300레벨까지 얼마나 걸릴까?”라는 질문에서는 캐릭터 이름과 목표 레벨을 읽고, 성장 이력에 기반한 계산 기능을 선택해야 합니다. 그런데 표현에 따라 이름을 놓치거나 필요한 기능으로 연결하지 못하는 경우가 있습니다.

잘 알아듣지 못한 질문을 모아, 어떤 표현에서 문제가 생기는지 확인하고 있습니다.

앞으로는 다음 작업을 진행하려고 합니다.

- **질문 이해 개선:** 같은 의미의 질문을 다양한 표현으로 물어봐도 알맞은 기능을 찾도록 개선하려고 합니다.
- **게임 정보 확장:** 아이템 이름으로 필요한 정보를 찾아 조회와 계산에 활용할 수 있도록 준비하고 있습니다.
- **애매한 표현 구분:** 리타를 부르는 말과 게임 캐릭터 이름처럼 여러 뜻으로 읽힐 수 있는 요청을 더 잘 구분하려고 합니다.

위 항목은 준비·계획 중인 작업입니다. 적용한 내용은 패치노트에 남기겠습니다.
